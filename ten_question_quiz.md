# Ten-question quiz: Reading charts responsibly

1. What does a chart's source note help readers do?
   A. Verify where the data came from
   B. Prove the chart's conclusion automatically
   C. Remove the need to check definitions
   D. Guarantee the data are error-free
   Answer: A

2. In UDISE+ 2023–24, the reported primary GER is 93.0%. What should a reader avoid concluding from this alone?
   A. That the reported value is 93.0%
   B. That GER is automatically the same as attendance
   C. That the value belongs to a school stage
   D. That the reference year is 2023–24
   Answer: B

3. Why should bar charts that show magnitude generally start at zero?
   A. To make the visual length proportional to the value
   B. To hide small differences
   C. To remove the need for units
   D. To make every bar equal
   Answer: A

4. The enrolment counts for primary and higher-secondary stages differ. Does that difference alone equal the number of students who dropped out?
   A. Yes, always
   B. No, stage counts do not track the same cohort by themselves
   C. Yes, if the chart uses blue bars
   D. Only if the title says “dropout”
   Answer: B

5. What should an analyst do with a missing value?
   A. Replace it with zero without explanation
   B. Hide the row
   C. Label it as missing and investigate
   D. Copy a value from a different year
   Answer: C

6. Which is the strongest chart title?
   A. “A shocking education crisis”
   B. “The government has failed”
   C. “Gross enrolment ratio by school stage, India, 2023–24”
   D. “The only truth about schools”
   Answer: C

7. Name two details that make datasets more comparable.
   Answer: Any two of: same reference period, same definitions, compatible units, matching geographic coverage, comparable denominators.

8. An AI assistant says that a lower higher-secondary GER is caused by household poverty, but the dataset contains only GER values. How should this claim be classified?
   Answer: Unsupported by that dataset; additional evidence is needed to investigate causes.

9. What important limitation applies to the UDISE+ 2023–24 pre-primary enrolment figure?
   Answer: It excludes enrolment in Anganwadi ECCE centres and private kindergartens outside UDISE+ coverage, as noted by the report.

10. Give one ethical practice for public data storytelling.
    Answer: Examples include citing every dataset, avoiding cherry-picking, protecting privacy, disclosing limitations, avoiding stereotypes, and checking AI-generated claims.
